CENTRAL GST HEN

GST HEN

Área de informações e tutoriais para usuários de PlayStation 3. Leia as instruções com atenção antes de alterar configurações do console.

O que é HEN?

HEN (Homebrew Enabler) permite executar determinados aplicativos homebrew em consoles compatíveis. A instalação e o uso variam conforme o modelo e a versão do sistema.

Antes de começar

  • Confira o modelo do seu PS3 e a versão do sistema.
  • Faça backup dos dados importantes.
  • Leia instruções confiáveis e específicas para seu console.
  • Não desligue o console durante processos de instalação ou atualização.
Esta página é informativa. Não há instalador ou arquivo de firmware incluído neste site.

TUTORIAIS

Como navegar pelo site no PS3

Use as setas do controle para percorrer os links. Pressione X para abrir. Use o botão voltar do navegador para retornar à página anterior.

Se o site não abrir corretamente

  • Atualize a página.
  • Verifique se a conexão com a internet está funcionando.
  • Ative JavaScript nas configurações do navegador, se estiver desativado.
  • Se alguma parte não aparecer, informe qual página e o que aconteceu para podermos simplificar o código.

Como limpar dados do navegador

Nas ferramentas do navegador do PS3, procure as opções de apagar cache e cookies. Os nomes dos menus podem variar conforme o idioma e a versão do sistema.
